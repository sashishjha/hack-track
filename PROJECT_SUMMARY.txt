🔧 HOW IT WORKS:

  Live Update Flow:
    User clicks "🔄 Update"
           ↓
    Frontend sends: POST /api/hackathons/refresh
           ↓
    Backend scraper fetches from:
      - Kaggle API
      - Devpost endpoint
      - Unstop (ready for setup)
           ↓
    Data gets parsed and aggregated
           ↓
    Saves to data/hackathons.json
           ↓
    Frontend reloads automatically
           ↓
    New/updated hackathons appear

  Remote Hackathons:
    - Auto-detected by scraper (location = 'Virtual')
    - Auto-added to data/hackathons.json
    - Frontend displays with "Remote" badge
    - Filterable by category

  Timeline/Calendar:
    - All hackathons have deadline metadata
    - Ready for calendar visualization
    - Example: "deadline": "2026-06-30T23:59:59Z"
